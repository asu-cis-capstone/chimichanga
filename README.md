# CHIMICHANGA

Repository for project Chimichanga — a Space Pirate themed mobile/web game developed by the ASU CIS Capstone team.

Idea

We set out to create a mobile-friendly game that is both addictive and rewarding. After researching popular games and gathering player feedback, we chose a Space Pirate theme with ASU CIS professors featured as bosses. The game uses custom hand-drawn artwork (pirate ship, ninja stars, meteors, etc.). Note: on some mobile phones you may need to zoom out to see all game features.

Availability

This project is open-source and all resources are available on GitHub. The game was developed with ClickTeam Fusion (a drag-and-drop development platform). We are keeping the game off official app stores (Apple/Google) for now to allow broader platform support. Our team purchased the ClickTeam Fusion "Pro" edition and the HTML5/JS exporter to remove limitations imposed by trial versions.

Metrics per Version

| Metric / Version                                | v1      | v2      | v3      |
|-------------------------------------------------|:-------:|:-------:|:-------:|
| % of players who would replay the game at least once | 83.33% | 70%    | 83.33% |
| % of players who would invite their friends    | 50%     | 60%     | 75%     |
| Average time spent playing (minutes)            | 2.33    | 5.4     | 5.5     |
| % of players who experienced technical difficulties | 83.3%  | 30%    | 20%    |

End Results

After three development iterations incorporating user feedback, metrics show encouraging improvements: technical issues dropped substantially (from 83.3% in v1 to 20% in v3) and the percentage of players willing to invite friends rose from 50% to 75%. Average play time increased after v1 and replay intent remained strong.
